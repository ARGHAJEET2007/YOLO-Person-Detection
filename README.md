# YOLO-Person-Detection
Real-time person detection using YOLO and OpenCV with detection data logging.

## Overview

This project implements real-time person detection using YOLO and OpenCV.

The system processes a live camera feed, detects people in each frame,
and records detection information for further analysis.

Only the  "person" class is processed, making the system focused
on human detection rather than detecting all available YOLO classes.
